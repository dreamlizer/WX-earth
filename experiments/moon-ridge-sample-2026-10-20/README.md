## 这次增加什么

| 时段 | 镜头与可见内容 | 通过条件 |
| --- | --- | --- |
| 0–10 秒 | 月面近景，迎面山脊与近处石块；低角度侧光形成大块阴影 | 起点不见地球，月面有空间体积；移动时近物掠过快于远处 |
| 10–14 秒 | 相机靠近并抬升，地球上缘先从山脊后露出，随后露出完整轮廓 | 通过地形遮挡显露，不是透明度渐显；没有闪现、穿山 |
| 14–23 秒 | 越过主脊，前方陨石坑与地球同框；相机逐渐减速 | 陨石坑、石块与远处地球构成不同深度，变化在原速观看时可辨 |
| 23–28 秒 | 固定构图停留 | 留五秒观看，不加字幕、粒子或闪光抢走注意力 |

共同创作，自定义 Three.js 三维镜头，不使用 Gallery 卡片配方或 Remotion 模板。用户已明确批准先做样段，采用实际 WebGL 动态画面作为方向评判依据。色彩限制为黑色宇宙、灰月壤、低饱和蓝色地球。地形为程序生成的镜头场景，不代表真实登月地点；未增加人物、飞船、音乐或新叙事。

## 已知质感边界

这版足以判断镜头变化与空间关系。近处山体仍偏平滑，月壤和石块仍有程序模型感；尚未达到最终月面资产精度。是否喜欢这条镜头方向，以用户看完样段的实际反馈为准，不以测试通过代替视觉认可。
