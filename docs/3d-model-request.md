# 找 3D 模型：简单要求

> 2026-09-29 状态：以下内容是 2026-09-09 落地试航阶段的模型需求，该路线已移出运行包；当前不再需要按本文收集登月舱或旅伴角色。现行登月方案见 [原版登月 MV 精修计划](original-moon-mv-refinement-plan.md)。

先找 **一台小型四脚登月舱** 和 **一个零号机或其他旅伴角色**，各一个即可。月面地形先不用找，本地已有占位地面。

## 可以直接发给模型提供者的话

> 我需要在微信小程序中实时展示的 3D 模型。优先提供 **GLB（glTF 2.0）格式，包含完整贴图**。希望是手机端可用的低面数版本，单个模型尽量约 1–2 万三角面，贴图优先 1024 或 2048 分辨率，文件尽量控制在 10 MB 以内。登月舱有清楚的脚架即可，不强求动画。角色最好有自然站姿并带骨骼；有待机、转头或行走动画更好，没有动画也可以先用静态模型。如果有 Blender 的 `.blend` 源文件，请一起提供。

这些数字是便于优化的目标，不是硬性门槛。你不需要自己判断面数：把链接、预览图或下载包发给我，我来检查。

## 只需留意三件事

1. **首选 `.glb`**：可以把模型、材质、贴图和动作装进一个文件，最方便交接。`.gltf` 也可以，但要把 `.bin` 和贴图文件夹一起打包。[glTF 官方说明](https://www.khronos.org/gltf/)
2. **不要只有渲染图片或视频**：需要能旋转查看的真正 3D 文件。若只有 `.fbx`、`.obj`，连同贴图一起发来，我再评估转换。
3. **人物想动，需要骨骼和动作**：商品页常写 `Rigged`（绑定了骨骼）、`Animated`（带动画）。只有 T 字站姿、没有骨骼的模型，可以先展示，但不能直接自然走路。

最好保留原始下载包、模型页面链接和随包说明。不要自行删掉不认识的贴图或辅助文件。

## 当前占位版本如何替换

已用简单几何体完成舱体下降、脚架接地、尾焰收起、站立人形和回望构图。正式模型到手后，需要做尺寸、方向、脚底位置、材质和加载器适配，再替换占位网格。原来的镜头和动作时间轴可以继续使用。
