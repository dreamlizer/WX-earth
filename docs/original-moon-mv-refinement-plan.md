# 原版登月 MV 精修计划：相遇与回望

状态：已按用户后续明确授权，将远地球与必要回望/末段推近接入右下角原 MV；本地实现完成，微信原生验收受阻。
2026-09-22 补充：终景固定光照、地球回望/遮挡与全曲音频时钟已接入独立试航。
本文件是当前方向；此前 `moon-voyage-storyboard.md` 的着陆创意和 `moon-trial.md` 的后续安排停止执行，保留作历史记录。

## 1. 已确认边界

- 以原版登月 MV 的星空、月球、音乐、歌词和伴飞素材为基础精修，保持原版的视觉气质。
- 右下角原版继续保留，行为、时间线、灯光、资源选择不变；原版并不因为改编版上线而被替换。
- 禅定后左下角沿用「试航」按钮，未来启动改编版；播放中仍是「返回」。不加第三个入口或版本选择面板。
- 104 秒落地试航已保存到 `archives/moon-trial-landing-2026-09-09/`，196 个文件完成 ZIP 完整性和逐文件 SHA-256 校验。包含源模型和共享接线上下文，不包含云端数据及依赖安装目录。
- 当前本次仅完成归档与计划，左下角实际仍连接旧试航。实施新场景时再改线，并让旧着陆模型退出运行依赖；没有声称已停用运行入口。
- 新版不包含登月舱、月面站立、着陆地形、骨骼角色、尾焰、脚印；原始模型留档。
- 新版的完成标准是连续画面的审美与叙事成立，不是模型能动或测试通过。

## 2. 现状与取舍

已核对当前代码：原版离地 38 秒、长廊 40 秒、近月 35 秒、绕月 130 秒；四段配置合计 243 秒，不代表实际歌曲时长。地球离场后显式隐藏，环绕累计 630°，后段构图变化有限。
原版已有星尘分层、速度起伏、两个伴飞角色和十二星座。此次重点是编排这些现成元素，避免简单追加粒子数量。

借用暂停试航中已验证的实体遮挡几何关系、独立场景和退出恢复机制；不直接搬用其 104 秒镜头、低分辨率预览质感或黑场着陆段。
画面以原版为参照：星空疏密、月球清晰度、色调和开场构图需逐项对照，避免做成新的简陋双球演示。

## 3. 完整歌曲的叙事安排

顺序先成立，时间码随后按实际音轨锁定。不能继续沿用“固定 104 秒截断歌曲”，也不为了填满 130 秒而重复绕圈。

| 段落 | 主要事件与构图 | 素材和运动安排 | 画面要传达的意思 |
| --- | --- | --- | --- |
| 出发 | 从熟悉的地球构图退远，逐步让出星空 | 保持原版的离地气质；地球因取景退出，不直接缩成零 | 离开熟悉的地方 |
| 相遇 | 一位旅伴先出现，另一位从远处靠近，短暂并行 | 使用现有两个平面素材，错开出场与远近；不要求握手、转身动作 | 我们开始同行 |
| 向月球而去 | 月球从远处目标成为视觉主体，伴飞者先后退场 | 长廊速度先有推进、接近时逐渐收缓；星尘减少 | 目的地越来越近 |
| 发现星座 | 选一两个现有星座，让连线短暂显现、再退回星空 | 安排在独立乐句或间奏；弱化文字，不与地球重现同时抢焦点 | 陌生宇宙中也有可辨认的形状 |
| 近月回望 | 完整月球转为画面一侧的大弧面，远处地球首次进入 | 景别改变，明确近月远地；月球仍在贴图可承受的距离 | 原来已经走了这么远 |
| 遮挡与重现 | 月缘缓慢挡住地球，停顿片刻后重新显露 | 连续段内地月固定、只动镜头；控制为一次清楚的事件 | 暂时失去，再次看见 |
| 终景 | 月缘留在侧下方，蓝色地球成为注意力中心，镜头逐渐停驻 | 留一个完整乐句；可选同一旅伴小幅入画呼应，若破坏构图就省略 | 抵达后的回望 |

星座段的位置可随间奏调整；重现地球是主要高潮，其他变化服务于它。画面中每次只安排一个主要事件。
两位角色在同次播放中保持身份一致；构图评审阶段固定素材，避免随机换人影响判断。

## 4. 先做三个关键画面

### 2026-09-22 确认：终景决定地月位置和绕月路线

- 最终停在近月空间，保留可见的月球/月缘，远方是较小但清楚、有蓝白细节的地球。这里的停驻不是登上月面。
- 以最终镜头的屏幕方向为准，月球和地球均呈现「左侧暗、右侧亮」。共享固定世界方向的太阳光；可见亮面比例由各自视线决定，不要求两者精确一半亮或分界形状完全相同。
- 先确定终景相机位置、朝向、地月位置及太阳方向，再反推进入绕月的路线。至少在进入绕月前固定这些空间关系；不能每次需要地球时重新把它摆进镜头。
- 不计开场离地，绕月段设计两次明确看见地球的机会：途中首次回望；地球被月缘遮住或暂时离开取景；最终重新显露并进入停驻构图。次数由路线与取景安排保证，不是绕月会自动出现两次。第二次重现直接衔接终景，避免又加一次重复揭示。
- 绕月途中太阳不跟随相机，因此不强求每一帧都左暗右亮；终景及其停留期间维持所确认的受光方向，不在结尾突然换灯来纠正。
- 终景相机停稳后，月表保留非常轻缓的自转观感，地球中心保持在远方稳定位置；两者受光方向和明暗分界整体稳定，不能让阴影随贴图一起转。明显可见的短时自转属于 MV 的艺术性时间压缩，不宣称为实时天文速度。
- 停驻描述的是终景段落，歌曲结束与返回流程沿用原计划，本次没有新增无限循环或曲末永久停留要求。

物理参考：NASA [Moon Facts](https://science.nasa.gov/moon/facts/) 说明月球自转周期约 27 天；[Moon Phases](https://science.nasa.gov/moon/moon-phases/) 说明受光由太阳方向决定、可见亮面随观察关系变化。最终构图及两次显露是本项目的镜头设计。

在与小程序一致的场景和材质里取景，不把概念图当作已实现效果。

1. **同行**：远近不同的两位旅伴短暂并行，星空有纵深，字幕有空位；不用左右往返代替互动。
2. **月缘与地球**：月缘占据一侧前景，小地球位于干净留白处；二者清晰可辨，画面不居中堆叠。
3. **回望终景**：月球弧线、蓝色地球和黑色留白构成完整画面，镜头静止时仍值得观看。

验收：原生模拟器中没有贴图糊、月缘锯齿、亮面过曝、暗部完全丢失、角色白边及字幕遮住主体。构图不成立时就在此阶段调整，不继续堆后续场景。

原版当前已经有未提交修改，保护基准是本次存档的工作区版本，不是盲目恢复 Git HEAD。

- 本轮规划不改 JS，因此不跑与文档/快照无关的全量回归，也不启动开发者工具。

## 地球可见性修正与快速验收（2026-09-22）

用户反馈完全看不到地球，不能继续要求听完整首歌验收。

- 原终景几何投影虽然入镜，390px 宽画面中地球直径仅约 22px，而且主要朝向暗蓝海洋。这不等于视觉上容易辨认。本轮将地球半径从 1.1 调至 2.6，固定位置不变，终景直径约 52px（艺术夸张），并旋转初始朝向，让受光面显示陆地。此数值不是天文比例。
- 保留真实深度遮挡和共同世界光源。测试新增手机尺寸下地球投影直径 >=48px；扩大后仍验证部分遮挡、完全遮挡、重现以及镜头连续性。
- 开发工具内试航新增“回望 / 遮挡 / 终景 / 播放”关键帧入口；检查画面时暂停音乐，播放时从所选时刻继续。普通真机不显示此工具。逻辑测试通过，原生点击验收受下述工具故障阻塞。
- 微信模拟器两次出现“长时间没有响应”，重启模拟器后仍卡在启动阶段。不能据此宣布本轮微信端视觉或性能验收通过。
