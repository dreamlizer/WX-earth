# 月球试航：104 秒叙事样片（含占位着陆段）

> 2026-09-27 状态更新：试航已整体移出运行包（`moon-trial.js`、`moon-trial-scene.js`、试航贴图与落地模型）。文件存放在 `archives/pending-delete-2026-09-27/`，本文件仅作历史记录。

> 2026-09-09 方向更新：本路线已暂停并存档；以下内容是历史记录。当前执行方向见 [原版登月 MV 精修计划](original-moon-mv-refinement-plan.md)。本次只完成规划，运行入口尚未切换。

禅定模式左下角「试航」进入独立地月场景，右下角仍是原版登月。贴图准备好、音乐开始播放后，按音频进度播放 104 秒，自动返回禅定；左下角「返回」可随时提前退出。进入后台时取消试航，回到前台再恢复禅定；页面卸载时清理资源。

## 本版剧本

| 音频时间 | 画面 |
| --- | --- |
| 0–12 秒 | 面向地球退远，让熟悉的地球逐渐缩小。 |
| 12–22 秒 | 镜头转向月球，一位现有伴飞角色进入侧前方。 |
| 22–36 秒 | 接近月球；角色短暂同行后退远、淡出。 |
| 36–49 秒 | 掠过月缘，逐渐带入远处地球。 |
| 49–65 秒 | 月球实体遮住地球，再从另一侧露出，完全遮挡约四秒。 |
| 65–77 秒 | 相机靠近并抬升，让月面成为下方前景、地球留在远方。 |
| 77–79 秒 | 近月回望停驻。 |
| 79–81 秒 | 短暂黑场衔接，从近月远景切换到局部着陆尺度。 |
| 80–89 秒 | 简单四脚登月舱减速下降，脚垫接触占位月面。 |
| 89–92 秒 | 舱体停稳，尾焰收起，人形在侧后方站立。 |
| 92–101 秒 | 镜头缓慢移向回望构图，带出舱体、人形和远方地球。 |
| 101–104 秒 | 终景停留，音乐渐弱，结束后返回禅定。 |

复用原登月歌曲 `Zen-moon.mp3` 的前 104 秒，暂未接全量歌词，也未按乐句人工精调。画面由音频 `currentTime` 驱动；音乐加载或播放失败明确提示，播放停滞超过 15 秒则退出。进入试航会暂停原禅定音乐和诗句，退出恢复原播放器及保存的诗句序号；加载中的迟到回调不能重新启动已退出的试航。

## 场景与资源

- `moon-trial.js` 包含场景流程和独立音频播放器，管理加载、取消、播放和恢复。原版登月保持独立。
- `moon-trial-scene.js` 创建独立 Scene、Camera、地球、月球、基础灯光、稀疏星空和一个伴飞平面。沿用主画布和渲染循环，同一帧只渲染一个场景。
- 地月共用一束固定方向的太阳光（方向向量 `(-10, 3, 2)`，强度 `1.35`），环境光降到 `0.018`。地球改用 Lambert 受光材质，保留少量亮度补偿；月球暗面不靠相机跟随补光照亮。不增加阴影贴图、后处理或新光源。
- 地月位置和尺寸固定，相机移动；遮挡由实体球面与深度缓冲完成，没有隐藏地球的角度开关。尺寸和距离服务于构图，不是天文比例模型。
- 地月本地贴图来自仓库现有素材：`earth.jpg` → `trial-earth.jpg`（512×256），`2k_moon.jpg` → `trial-moon.jpg`（1024×512），合计约 275 KiB。
- 伴飞复用 `Flying/EVA00.png`，缩小为 `trial-companion.png`（288×512，约 190 KiB）；Shader 去除白底，只安排中远景平面同行，没有新增角色建模或姿态。
- 音乐只在用户点击试航后下载，临时文件可复用；不增加后台云资源预取。
- 场景仅释放自己创建的资源。适配包实际使用旧版 `gammaOutput` / `gammaFactor`，试航帧临时启用输出校正并在帧后还原。
- 保留透明 Scene 背景，由页面提供黑底，避免实色画布挡住浮层。左下角同一个按钮切换「试航 / 返回」，使用画布下方已有的 96rpx 留白中的 cover-view，播放时带深色底，不依赖模拟器原生画布的覆盖层排序。
- 左下角旧十倍速热区仅在原版登月播放时接收触摸。

### 占位着陆段（2026-09-09）

- 已实施：舱体、人形和月面均由本地简单几何体生成，不新增下载模型、贴图或解码器。舱体和人形各合并为一个网格；人形是等待者的固定站姿，尚未实现出舱、走路或转头。
- 局部着陆场景与远景分别取景，地球保持约 2.3° 的视直径和原来的材质朝向，太阳使用相同世界方向。通过两秒黑场衔接尺度变化；这不是无剪辑的等比例着陆模拟。
- 脚架最低点为 y=0，九秒下降结束后锁定高度；尾焰随后熄灭。阴影沿固定太阳方向投到平坦接地区，没有启用阴影贴图。投影保留极小厚度，避免旧渲染器出现不可逆法线矩阵警告。
- 局部地面目前为灰色低细节占位，局部阴影也只针对这块平坦地面；正式崎岖地形需重新评估阴影和接地点。

## 2026-09-09：真实静态模型接入

试航最后 24 秒已使用用户提供的 NASA Apollo 登月舱与黄色 EVA-00，替换可见的几何占位物。原始 GLB 保留在 `source-models/`，只对副本做离线处理。原登月入口及时序不变。

- Apollo：97,588 → 28,530 三角面；157 个原始 primitive 合为一个主体绘制。
- EVA-00：3,692 三角面、一个主体绘制；自然站姿，尚无骨骼、转头或行走。
- 两个模型各使用一张 1024×1024 PNG 图集及一份 MV01 二进制，合计约 1 MiB 包内资源；只在进入试航时读取。手机端不解 Draco、不解析 GLB。
- 统一漫反射太阳光；源模型的 PBR 高光未保留。地面阴影继续使用原先低面代理，属于近似轮廓，不是精确模型投影。
- 按局部镜头艺术比例归一化，脚底 y=0，登月舱高 2.25、角色高 1.65；不表达 EVA 与 Apollo 的原作真实尺寸关系。
- 离线构建过程见 `tools/model-build/README.md`。未来骨骼版从原始资产处理，不从静态扁平数据恢复骨骼。

验证：26 个测试文件通过。新增真实资产三角面数、脚底及高度、UV 方向检查；模型读取失败、取消后迟到回调不复活资源检查通过。

微信开发者工具中观察到真实模型贴图、下降、落地、地球收尾同框，连续两轮播放后正常返回禅定并恢复诗句；第二轮重复进入能重新加载。关键帧墙钟约 86.6 秒仍在下降、96.1 秒落地、102.0 秒地球与两个模型同框（墙钟含加载时间，不等同音乐时间）。模型接入前已有 1 条内核错误基线，播放后错误计数仍为 1；有既存补光修正、诗句等警告，不声称零控制台告警。
