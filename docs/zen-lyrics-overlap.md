# 禅定歌词交接避让（2026-09-22）

三首禅定曲目共用 DOM 文字布局，保留原来的淡入淡出与歌词时间轴。`APP_CFG.poetry.maxOverlapRatio = 0.10` 控制相邻两段的矩形交叠面积，分母为两个实际文字框面积的较小值，避免短句被长句大面积盖住。

新段落先测量文字尺寸，参考旧段落当前及余下移动范围选位置。对新段落整个漂移范围做保守检查，先尝试移位，再尝试不漂移；实在放不下则即时收起旧句，新句仍按原节拍显示。该限制针对文字外框，不是逐像素字形或发光阴影面积。

原生模拟器中发现原来 120ms 测量超时会回退为 80×160，导致英文长句尺寸被低估。只对禅定普通歌词将测量等待上限改为 500ms；失败返回 null，按整个可用区保守处理、避免两句同时显示。其他调用方保持原有默认值。

验证：27 个测试文件通过。新增覆盖横竖排、不同文字框大小、移动全程、无空间回退、测量失败，以及曲目 1/102/103 的管理器交接。微信开发者工具抽查三首曲目显示/切换和交接画面；第二首长句交接清楚分离、完整显示。未宣称全曲逐帧或真机已验收。
