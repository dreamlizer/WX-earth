## 3. 最新正式时间线（以运行代码为准）

基础配置 `earthExitSec=38`、`corridorSec=40`、`moonApproachSec=35`，因此节点为 38 / 78 / 113 秒。113 秒进入原绕月，后续不变。

| 阶段 | 正式时间 | 当前实现 |
|---|---|---|
| 第一艘 | 10–42 秒 | 首帧记录地球的相机空间方向。32 秒单一直线，终点 x=-0.3、y=0.08、z=1.2；固定朝向 [0.28,0.4,0.45]。近距离机身/天线盘掠过左侧，允许轨迹延伸到相机后方，不在 z=-0.1 提前隐藏 |
| 空档 | 42–47 秒 | 没有飞行器，保持星空/原背景 |
| 第二艘 | 47–79 秒 | 将样片36秒动作映射到32秒；约12.44秒接近、8.89秒伴飞、10.67秒超过。模型大小固定，有轻微相对漂浮 |
| 第三艘 | 通常79–112.35秒 | 月球真实投影可见才触发；从下方出发，以固定最终月面落点为目标。进度 q=(elapsed/duration)^1.3。固定尺寸 baseScale*0.3，靠近镜头匹配视觉体量；最后1.4秒淡去 |
| 月面闪点 | 112.35–112.95秒 | 0.6秒小四角星芒 |
| 原绕月 | 113秒起 | 原轨道与后续效果 |

第三段若资源延迟/画幅变化导致 Moon gate 晚触发，其可用时间会缩短到113秒前；当前只验证了390×720构图，真机其他画幅应重点观察是否变赶。

月球接近起始侧向偏移已由 -0.22 调成 -0.04，使第三段开始时能看见月球；没有改变最终月球位置 `(-5.8,-1.2,0)`、尺度0.9和113秒绕月节点。第三段落点直接依据这些最终值计算，未来改最终位置时必须一起检查。

- `miniprogram/pages/gl/moon-voyage-star-flow.js`：共享近景星流，840星点+840短拖尾，持续存在、横向转纵深、伴飞减速、超过时加速，逐渐增加可见密度。
- `miniprogram/pages/gl/moon-orbit-sequence.js`：已确认的绕月、远地球、太阳光和最终推进；本轮不应顺手重做。
- `miniprogram/assets/models/voyager/model.js`：小程序模型节点、材质、buffer元数据。
- `miniprogram/voyager-assets/`：geometry.bin、4张PNG、分包入口及ready.js。
- `miniprogram/app.json`：已声明 `voyager-assets` 资源分包。
- `source-models/voyager-nasa/Voyager.glb`：原始模型；`tools/model-build/prepare-voyager.py`：移动端资源转换。
