# 太阳帆材质与构图试验 · 2026-09-28

使用 NASA Solar Sail Concept 原始 GLB 的独立副本，非 AI 生图。复现：Blender 后台运行 `tools/solar-sail-lookdev/render.py`。

- `01-source.png`：同机位、同灯光的原材质对照（几何处理与调整版一致）。
- `02-silver-sail.png`：银灰薄膜、细微凹凸、侧斜机位的效果探索。
- `solar-sail-lookdev.blend`：可编辑的真实模型渲染场景。

源模型保留不变；预览副本清除自定义法线、合并重叠顶点、重算法线。帆面有自阴影黑斑，当前预览关闭模型的投射阴影；不能视作已解决移动端模型质量。原几何仍有明显折面。

这是 Cycles 离线材质/构图参考，不是微信截图，不是现有 MV 场景，也不承诺同等实时效果。使用两盏画外面积光以检验反射，程序细纹尚未烘焙为移动端贴图。后续如果采用，要把法线/粗糙度烘焙到贴图并在项目引擎复核；不改变既有地月光照来迎合此预览。

本轮未修改小程序、未加入飞行或随机机制。
