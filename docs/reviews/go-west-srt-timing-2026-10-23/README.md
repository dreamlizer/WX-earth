- 保留原LRC、全部66条原中英文、布局、字号、动效，以及仅05—08号Together的叠影/小幅波浪。
- 最新SRT已原样复制为 `source-lyrics/go-west-jianying-20261023.srt`。运行包只包含校正时间及来源说明，不携带识别错词。
- 51组原唱句有SRT时间关联。独立拆分的Together/We will find、第三段第一组Go West/Life is peaceful、尾部三组Go West/跟唱分别取SRT独立时间。多数SRT把上下句合并，没有逐词时间：按同类已拆分声部的节奏比例估计分界，并标为 `merged-cadence-estimate`。2:10附近领唱与上一行farewell混淆、2:54重复We'll find、3:02跨行To live、3:10—3:22跨行断句、3:59未识别destiny及过渡尾句单独标记兜底或估计。这些不能当作逐词听音验收。

- Go West歌词采用不落后于原生音频最新样本的时间，保留平滑时钟用于场景；不修改公共 `ZenVisualClock`，也不修改其他歌曲。
- 整组通常以跟唱结束+0.22秒余韵+0.30秒淡出确定共同退场，允许至多两组短交叉，避免截掉上一组末音或延误下一组入场。英文上下句、中文上下句共同退场。过渡13—14仍共同叠放，给下一主歌留0.8秒空隙。终场247.10秒清场上限优先，248.10秒撒花不变，53—55继续隐藏。
- 星字/霓虹强调从本次领唱起保持到下句开唱前0.05秒，结尾最多0.25秒回落到底光；字本身持续保留。第八次霓虹最强通电直到整段退场，四档递进和A—B—A形式保留。
- 原声轨、片头、地球转动/球灯、六次背景全局闪耀、EVE和终场均不变。测试逐50ms比较本轮前的场景frame，覆盖0—260秒，确保这些参数完全一致。
