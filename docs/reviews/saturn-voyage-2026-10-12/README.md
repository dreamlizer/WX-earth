# 土星航线首版 · 2026-10-12

入口：主页左下角「土星预览」→「开始航行 · 约 2 分钟」。

## 体验

- 0–36 秒：从完整土星远景逐渐靠近星环，下降到环面附近。
- 36–92 秒：沿冰环绕行，近处冰块与远处巨大的土星形成视差。
- 92–116 秒：进入土星遮挡太阳的区域，星环和冰块逐渐失去直射光。
- 116–132 秒：在阴影中放缓，终点自动暂停，保留拖动观看。

单指拖动改变视线，航线位置继续由相机路径控制；「暂停航行」冻结航行、云层与冰块运动，暂停期间仍可拖动。「回正视线」恢复默认观看方向。「重新起航」从头开始；「模型预览」平滑返回原来的整体观察视角与材质风格。右上角可返回地球。

复用当前土星纹理、星环材质、1900 个合并绘制的冰块和 Three.js；没有新增贴图、依赖、音频或飞船模型。阴影来自已有行星遮光计算。路线以观感为目标，不是航天器轨道仿真。
