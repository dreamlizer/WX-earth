# 土星四版实际预览

主页左下角「土星预览」进入，底部切换原版 / 观测 / 电影 / 逆光。三种镜头预设和拖动、双指缩放继续可用；切换材质保留镜头，不重载纹理。默认观测版。

| 版本 | 实际变化 |
| --- | --- |
| 原版 | 保留 Solar System Scope 环图和原 Spacekit 改编 shader，用作比较 |
| 观测 | Björn 径向数据、自然色照明、视角相关环透明度、细环阴影 |
| 电影 | 同一数据，侧光、较深暗面、暖色云带和薄大气层 |
| 逆光 | 太阳处于观察者对面的环平面侧，使用未照亮侧亮度剖面及透射公式，厚薄环出现不同明暗 |

新增版本复用 [Björn Jónsson 星环数据](https://bjj.mmedia.is/data/s_rings/) 和 [I,Voyager 的星环反射/透射方法](https://github.com/ivoyager/ivoyager_core/blob/master/shaders/rings.gdshader)。移植的是均匀薄层公式、双面判断和光学厚度，不是整个 Godot 引擎。未移植其完整光度标定、多天体遮挡、PSF 和远距离亚像素模型。电影和逆光是视觉布光方向，不能称为科学实测外观。

球面仍共用已有 4096×2048 土星色图。本轮主要改进星环和光照，没有换成更高分辨率云带贴图。没有新增运行依赖、粒子星环、离线视频或 AI 合成背景。

## 数据与转换

五个原始文本各有 13177 条记录。环半径 74510–140390 km，按土星赤道半径 60268 km 归一化。影像剖面已经重采样，不把它们宣称为原生 5 km 彩色影像。PNG 为 4096×16 RGBA、22672 bytes，三个剖面分区各重复四行；RGB 平方根编码有效散射强度，alpha 编码法向光学厚度。转换用代表性仰角 0.35 反求亮度，避免再次完全套入拍摄几何；不是对源照片曝光进行完整拟合。见 `tools/model-build/prepare-saturn-profiles.py`。

保持异步分包 require。Shader 兼容现有 Three r108 / WebGL 1；星环及环投向球面的阴影使用四次径向采样减少细纹闪烁，支持导数时使用像素覆盖宽度，否则使用保守宽度。不同版本复用网格/纹理，共用现有渲染循环；退出释放所有版本材质，包括未显示的材质。
