# Go West 粉色像素人名接入

2026-10-23。用户授权先修正独立预览的像素退场，再将该像素效果接入小程序。

## 效果与边界

- Pet Shop Boys改为635颗细方块组成的像素字，沿用已确认的大小差、少量缺口、深粉/灰粉/浅粉/淡紫随机深浅。入场按固定种子错峰亮起、归位；成形后保留原独立缓移。
- 退场前约30%的时间先向不同方向四散，稍作停顿，再逐颗向真实地球弧线坠落。像素散开时保持亮度并略放大，避免微小颗粒看似凭空消失；落下时延后向深处推进，留出可见的下落过程。透明度保持1，最终通过球体深度遮挡隐去，不用提前淡出替代入球。
- 独立视频预览仍用23.7—26.2秒的演唱者退场安排；小程序保留自身28.62—31.22秒时段，不照搬视频时间。歌名、地球旋转、歌词（含手机上句提前）、球灯、星空、EVE及终场均保留现有实现。
- 小程序沿用现有go-west-opening-motion.js承载位图和运动纯函数，GoWestOpening3D把全部像素合并成一个网格、一个材质，复用属性缓冲；不创建635次绘制，不增加运行时字体或图片下载。保留已有其他歌曲和文字资源，不清理无关文件。
