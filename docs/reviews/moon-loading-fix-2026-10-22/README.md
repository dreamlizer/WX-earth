## 修改

- 起航只等待月球两个必需分包与原音乐。Voyager 等可选模型在后台启动，不进入起航 Promise；保留并发调用去重和生命周期检查。
- Voyager 增加 30 秒加载预算。超时后本次不逐帧重试；退出时取消预算；已收到及迟到贴图释放；不会取消独立的高达/EVA/机器人/星舰。分包加载底层不可主动中断，但迟到结果不能复活对象。
- 当前 Three r108 无 `initTexture`，所以采用真实离屏绘制。月面逐张采样上传贴图并在各张之间让帧，再离屏绘制近、远两种姿态，准备几何、人物及阴影资源。完成实际绘制并检查新 shader 链接后才 ready。
- 月球衔接所用的原月球 shader 与法线材质变体提前到准备阶段；193 秒进入时不再设置 needsUpdate 或重新追加 shader。
- 照片在后台准备时就分配当前屏幕所需的渲染目标，再用独立小目标实际采样照片与背景目标，避免自身读写。此时不会触发照片可见、曲终保持或保存/返回 UI。
- 每次离屏操作恢复共享渲染器的目标、立方体面/层级、视口、裁剪、autoClear 和阴影更新状态，再让出时间。场景级光照设置沿用原有 try/finally 恢复。
