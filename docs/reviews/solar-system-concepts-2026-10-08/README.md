![离开地球](01-earth-departure.png)

## 2. 太阳系展开：第一次看见更大的关系

![太阳系展开](02-solar-reveal.png)

进入后的探索总览。太阳与内行星在远处，木星成为近景，土星与外行星向另一侧延伸，斜向轨道贯穿竖屏。3D 参照重点：用透视和景别组织信息，细轨道、太阳光与球体明暗统一；不要求所有天体始终完整同屏。

## 3. 靠近土星：庞然大物悬在面前

![靠近土星](03-saturn-encounter.png)
