## 加载与退出

普通/禅定模式不预取新尾段。实际起航后后台下载，最多2个并发，按文件大小和MD5校验，写入本功能版本缓存。纹理解码逐项进行，人物构建、shader预编译在显露前完成。

180秒决定本次是否就绪；未就绪、加载失败或GPU不支持时整段继续旧尾段，不停音乐等待，不在末段临时换材质。已就绪时，191–193秒让原绕月路径平滑减速，193秒将相机所有权交给新尾段。

读取原音频时间并在采样间平滑推进，不在193秒重开播放器。缓存损坏只重取对应文件；退出中止可取消的下载，生命周期令牌防止迟到回调复活场景。临时CDN域名被设备拒绝时，回退原生CloudBase下载接口。本功能只清理自己的旧版本目录。

尾段用独立Three.Scene和相机复用原renderer，保留原地球对象、材质与交互状态。退出继续既有黑幕流程；音乐自然结束后恢复主页，地球拖动已实际检查。

## 适配时解决的实际差异

- 浏览器r160与小程序r108的几何、UV、法线shader和阴影API不同。使用r108的BufferGeometry/addAttribute/Math/inverse等接口，保留物体空间法线与已有PC纹理修正。
- 实际预编译曾发现r108不存在新版 `receiveShadow` uniform，已修复；增加真实GL程序链接检查，失败不标记ready。
- r108旧PBR光照会额外乘π，ACES也是旧近似。新尾段内部启用物理光照，进入时补偿原亮度，再平滑到已确认照明；本段材质使用r160对应ACES拟合与正确sRGB输出。每次渲染后恢复共享renderer参数，没有全局调整普通地球或其他歌曲。
- 现有星空几何、材质参数与相位被复制到本段，并在接点对齐原星点位置，再缓慢过渡到已确认尾段参数，避免重新随机生成造成星空跳变。
- 整体地形阴影从预览4096²改为2048²；人物局部2048²阴影保留，以保持靴底、撑手和坐压接触。全景月球球体减为128×64分段，局部地形与人物几何未简化。
- 当前完整材质要求至少12个片元纹理采样器和2048最大纹理尺寸；不满足时保留旧尾段。没有把桌面参数或截图采样速度称作手机性能。
