# 高达与两台 EVA 的追逐接入

用户确认：高达先跑；紫色初号机从左后方先入画，红色二号机晚 0.5 秒从右后方跟上；三机有前后错落、自然飞姿和更短的 EVA 尾迹，最后逐个消失。

## 实现

- `moon-voyage-eva.js`：两台 EVA 的独立资源加载、定时 Hermite 飞行曲线、整体侧倾/转向、短喷流、退出与迟到回调清理。
- 初号机先向画面内侧靠近领跑高达，再随其转向左前方；二号机稍后从右侧汇入。不是在两侧各自飞走。
- 实际 390×720、45° 相机下首个可见模型顶点为 83.06 / 83.56 秒。红色形体比紫色窄，增加 0.05 秒轨迹补偿，确保可见入画差为 0.5 秒。
- 84–89 秒三机完整模型顶点在画内，高达在前、紫色居中、红色稍后；初段纵深距离收近。高达后段横向偏移收小，90 秒仍在画内，90.5 秒结束；紫色 90.7 秒、红色 91.2 秒结束。小机体在远处短暂渐隐。
- EVA 短喷流和余辉复用高达的噪声着色，寿命 0.45 秒（高达 0.85 秒），限制物理长度和扩散宽度；高达余辉 90.95 秒清空，红色最后余辉 91.55 秒清空。92 秒星舰、113 秒原绕月、音乐/歌词、主相机、月面尾段均沿用。
- EVA 采用与高达一致的局部装甲主光/轮廓光，保留紫红配色，未改全局灯光。
- 两台作为一组准备，不显示只有一台的半成品；退出立即释放已准备机体，未完成 I/O 的迟到结果不能复活场景。
