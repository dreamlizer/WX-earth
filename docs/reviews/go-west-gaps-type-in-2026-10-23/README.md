# Go West 恢复句间空白与过渡逐字入场

用户要求只调整普通字幕的结束时间，保留上一轮校正后的入场，恢复原来大致的空白间隔；13—14号里的三条文字改为逐字出现。

## 改动

- 从改SRT前的旧版逐句间隔计算空白（整体提前1.2秒不会改变这个差值），再用新轴的下一句入场反推前一句退场。只改普通唱句结束时刻，校正后的上/下句开始、演唱锚点、歌词内容不变。原空白为0的边界也不再交叉；第二至第八组Together之后的空白分别约0.33、0.55、0.14、0.33、0.30、0.37、0.23秒。
- 撤掉上一轮普通唱句的额外余韵/交叉淡出安排。中英和上下句仍共用退场；GPU副歌的整段尾部随组退场同步，第八次霓虹继续亮到段尾。终场清场、撒花、片头、球灯和音轨不改。
- 13—14号的三条文字改为逐字入场。英文复用Together跟唱已确认的小幅逐字波浪；中文沿用前景GPU文字纹理，按完整字符宽度依次揭示，位置与字体不变，不水平压缩，也不每帧重画纹理。
- 保留这三条原本有意安排的叠放和共同退场、下一主歌前0.8秒空白；不把它们当作普通唱句重叠删除。
- 首句入场仍为34.800秒，独立预留及本曲歌词时钟处理保持不变。

`before/` 保存本轮前相关实现与测试，包含已有并行改动。逐句退场和旧版空白见 `gap-verification.json`。最新显示时刻同步在[主对照表](../go-west-srt-timing-2026-10-23/display-timeline.md)。
