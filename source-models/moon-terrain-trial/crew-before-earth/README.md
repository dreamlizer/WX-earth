# 坑缘三人先出现，再看见地球

独立预览：http://127.0.0.1:8970/moon-terrain-trial/crew-before-earth/index.html

启动：在项目根目录执行 `node source-models/moon-terrain-trial/crew-before-earth/server.cjs`。绑定本机地址；不发布、不接入小程序。播放、暂停、从193秒重播、时间滑条、静音均可用，滑动时间会暂停。音乐继续复用193版从原曲解码的PCM尾段，原曲193–271.726667秒，共78.726667秒。

## 镜头安排

| 原曲时间 | 画面 |
| --- | --- |
| 193–212秒 | 从原有第二圈远景锚点接近月球，下降至完整环形山的悬空视角 |
| 约216–219秒 | 三人从画面右侧逐渐进入，219秒三人完整可见；地球仍在画外 |
| 219–约225秒 | 先看他们望向远方，缓慢顺着视线转向 |
| 约225–228秒 | 右侧地球逐渐清楚入画；几何边缘最早223.60秒擦入，暗侧细边不等同于清楚看见地球 |
| 229–238秒 | 保持已确认B镜头：完整环形山、三人背影、远地球、星空 |
| 238–255秒 | 缓慢抬视线，月面向下退，让宇宙留白增多 |
| 255秒至曲终 | 镜头静止，保留三人及下方坑缘，同望远地球；地球按原速度缓慢自转 |

三人固定坐在环形山远侧坑缘，x/z分别为(25,-19)、(34,-20)、(43,-19)，高度由成熟地形网格向下射线求交；身体朝向远地球。人物不随镜头移动、不做透明淡入。远景距离剔除在人物尚在画外时完成；近景始终可见。场景单位未标定为米，人物比例为这一构图做视觉调整。

## 三维资产与光照

本版是真实静态三维GLB：绫波丽短浅蓝发/白黑驾驶服，碇真嗣短黑发/白蓝黑驾驶服，明日香长橙红发/红黑驾驶服；均不戴头盔。为本样段自行构造的简化背影模型，重点验证比例、坐姿和镜头关系，不能等同于此前生成图的精细成品或官方角色模型。没有图片人形面片；无骨骼，当前不能直接播放骨骼动作。位置、旋转、缩放可直接改，服装和发型可在源码中修改后重新导出。

- `characters.js`：人物形体、发型、服装、坐姿和落座位置。
- `export-models.mjs`：执行 `node source-models/moon-terrain-trial/crew-before-earth/export-models.mjs`，重新导出三份GLB。
- `assets/*-seated.glb`：预览实际加载的三份模型；总计100800三角形、22个材质批次、2639052字节，尚未作微信端性能验收。
- `camera-path.js`、`end-pose.json`：连续镜头和最终悬空机位。
- `earth-calibration.json`：根据小程序地球参考姿态重新换算；地球中心视图中太阳方向x=0.92434、y=0.31553，来自右上方。所有人物、月面与地球共用同一方向光，人物有真实投影，影子落向画面左侧。
