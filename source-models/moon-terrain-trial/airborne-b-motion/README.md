# 月面 B · 悬空环形山动态样段

2026-10-21。20 秒、540×960（9:16）、无声的独立 WebGL 预览。方向沿用已确认的 B「环形山中景」，等待用户评价动态观感；没有接入小程序、音轨或歌词，没有上传发布。

预览：<http://127.0.0.1:8966/>。播放/暂停、重播、时间滑条、B 基准帧均位于画面外。页面默认停在 0 秒，点击播放。结束后保持 B，点击播放或重播均从头开始；拖动滑条会暂停，再点播放从当前位置继续。

在项目根目录启动（先检查 8966 占用，已有本服务则复用）：

```bash
lsof -nP -iTCP:8966 -sTCP:LISTEN
node source-models/moon-terrain-trial/airborne-b-motion/server.cjs
```

服务只绑定 127.0.0.1。此目录依赖仓库内共享文件，不能只复制 HTML 后直接打开；无需下载、构建或重新转换地形。

## 文件与资源依赖

- `index.html`：画面与外置控件；`viewer.js`：场景、绝对时间运镜、播放和关键帧输出。
- `shot-config.json`：时长、画幅、Bezier 控制点、B 基准参数、关键帧时间。修改相机仅需编辑此配置并刷新。
- `server.cjs`：本地静态服务，映射地球贴图；写入端点仅允许本目录指定输出文件。
- `output/contact-sheet.png`：6 张实际 WebGL 渲染关键帧，1656×2064；`frame-00/05/10/14/17/20.png` 为各 540×960 原图。
- `output/validation.json`：1201 个 60Hz 时间样本的连续性/高度边界统计、每秒姿态、完整自然播放统计。
- `output/image-check.json`：B 基准逐像素比对与原图哈希；`output/project-tests.log`：本次 41 个项目测试日志。

复用的月面文件共 **5,734,067 字节（约 5.47 MiB）**：`../preview/assets/terrain.glb`、`albedo.jpg`、`roughness.jpg`、`ao.jpg`，以及 `../airborne-comparison/assets/normal-object.jpg`。网格 scale=100，80,000 三角面。保留修正后的 ObjectSpaceNormalMap；没有重新造地形或恢复旧法线接法。

公共 Three.js/GLTFLoader 来自 `../../mech-encounter-candidates/preview/vendor/`（加载器相对依赖保持原状）。`/earth.jpg` 映射到项目 `experiments/moon-ridge-sample-2026-10-20/assets/earth.jpg`。上述体积不含公共代码、地球贴图与渲染缓冲；纹理显存估算沿用 B 的约 53.3 MiB，非手机测量。

灯光、曝光、地球位置、材质与 B 基准相同。地球固定 (0,95,-520)，没有瞬移或假淡入。地形与太阳静止，首帧生成的 4096² 阴影图全程复用，避免摄像机运动引起阴影重拟合。4096² 是桌面基准，不代表手机配置。

## 相对时间与镜头

| 时间 | 画面 |
| --- | --- |
| 0–5 秒 | 悬空接近坑缘，主坑整体已可辨，侧壁以较浅角度呈现 |
| 5–12 秒 | 侧向移动并缓慢升高，以三维视差展开坑底与坑壁 |
| 12–17 秒 | 渐缓进入已确认 B，接近停稳 |
| 17–20 秒 | 精确停留在 B，留给观众看清完整环形山与远地球 |

起点 (85,47,135)，终点 (55,60,140)，看向 (25,8,-60)。四个空间控制点和全局五次缓入缓出均在配置/源码中记录。位置和朝向由绝对时间重建，不累积位移；末端速度与加速度归零。没有滚转或镜头切换。

数值是未标定的场景单位，不是实际米数。为保持已确认构图，远方地球从开场已可见，不强求越岭遮挡。结尾准确停留，未新增晃动、飞船、尘雾或特效。

## 实际验证

- 在 Codex 内置浏览器从 0 秒正常速度播放到 20 秒，观察开场、展开、入 B 和结束停留；记录 1201 次绘制，最大帧间隔约 17.7ms。仅代表本机本次桌面运行，不是手机性能指标。
- 检查 0/5/10/14/17/20 秒实渲染帧。首轮曾暴露近端边缘，已收紧起始航线并重新播放、导出；最终未见近端/侧面矩形断边、穿模、地球裁切或阴影突跳。远轮廓仍来自原有限地块，不代表真实球形月球地平线。
- 1201 个 60Hz 姿态样本中，相机最低点仍高于整个地形最高顶点 **26.5733 场景单位**，为保守无碰撞依据。相机不在有限地块正上方时，垂直射线无命中，因此没有虚报精确离地高度。
- 最大相邻位置差 0.08453 场景单位，最大朝向差 0.02392°，无分段跳变；17–20 秒姿态固定。
- `frame-17.png` 与已确认 `comparison.png` 的 B 画面区域逐像素完全相同，17/20 秒图也完全相同。原 comparison.png 和 viewer.js 的 SHA256 保持不变。
