# 月球纪念照：无声独立动态预览

本地入口：<http://127.0.0.1:8978/moon-terrain-trial/crew-keepsake-motion/index.html>。

双击 `启动无声预览.command` 可重开后台预览服务。旧版8977、全部旧样段、原照片和小程序源码保留。

## 本版效果

- 默认暂停在263秒，点「播放结尾」即可看结尾；「重看结尾」从263秒重放，「从193秒播放」可看完整原月面段。
- 266.94秒开始0.11秒快门收暗，267.07秒起由快门遮罩揭开不透明照片，避免半透明照片产生两颗地球的叠影。原3D背景继续渲染，逐渐压暗并轻微虚化。
- 细窄暖白相框，下沿略宽，投影让照片与背景分离。照片高度从画面的61%缓慢增长到84.5%，约8.5秒收住；旋转从−2.4°缓缓过渡到约+1.1°。
- 曲终271.7267秒不退出、不自动重播。相框继续非常轻的位移与转动；背景星空和地球继续渲染。照片遮住背景原有三人与地球的中心区域，四周保留星空和月面。
- 播放、暂停、滑条和照片运动共用单一网页呈现时钟。暂停会停住全部运动，拖动会暂停，重播会重置照片状态。
- 没有音频元素、音频播放器或快门音效，不下载原音乐。纯无声预览。

## 复用与边界

3D场景直接导入 `../crew-grounded-motion/scene.js`，相机、人物、地形和近景贴图均复用。其文档相对路径读取的 `earth-calibration.json` 在本目录放一份相同配置；其他跨目录资产由专用服务器白名单提供。服务仅监听127.0.0.1。

照片通过 `/keepsake-photo.png` 指向已有 `../ending-keepsake-photo/photo-v2-anime.png`；没有复制或重生成照片。最终可见画布为540×960的2D合成画布，背景来自复用场景的实际WebGL渲染，照片通过同一画布合成，方便导出完整相框关键帧。

只实现用户本次授权的网页模拟，没有改动或接入微信小程序，没有上传发布。此网页检查不代表微信开发者工具或真机验收。
