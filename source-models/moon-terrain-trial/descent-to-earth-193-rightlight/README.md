## 本轮修正

1. 从微信开发者工具正在运行的正式登月场景采集255秒相机、地球四元数、太阳方向和实际RGBA帧，记录于`docs/reviews/moon-contrast-2026-10-21/earth-reference-255.*`。初始化按103→104→112.9→113.01→154→255秒顺序，确保月球半径0.9、地球半径1.156503，避免跳时把未显现的1e-6占位尺寸当作有效参考。
2. `calibrate-earth.cjs`把正式地球的姿态、太阳方向转换到“相机看向地球中心”的坐标系，再转到新终景。匹配的是观众看到的海陆朝向、地轴倾斜和明暗相位，不是手填rotation.y=2或水平镜像。太阳在该坐标系为`[0.924339,0.315535,0.214559]`，明确来自右上方。全程使用同一个固定太阳方向，地形和地球一起受光。
3. 复用正式`preview-day.jpg`、`preview-cloud.png`，地球与云层同用Lambert材质、云透明度0.58；地球在255秒姿态上以原速度0.009 rad/s自转，云按原261秒锚点漂移。浏览器与小程序Three版本、色彩输出仍不同，不宣称像素或真机外观一致。
4. 原轨道193秒的相机锚点采用可落到右侧受光区域的另一组刚性坐标变换，后续镜头节点/阶段时长保持原节奏。初帧相机姿态与原轨道构图检查场景一致；它不是对正式193秒整帧的录屏复制。
5. 修正右侧光向暴露的有限地块方形投影：全月球底层不接收局部地块投影，近景地块保留自阴影。地块几何高度与颜色/法线共同按观察距离平滑展开；远距权重为0时不绘制地块，近景几何完整后平滑加入对应自阴影，避免远景悬浮坑缘和矩形黑块。未修改原GLB或源贴图。

## 源码与依赖

- `scene.js`：球形月球、成熟地形、阴影、实际地球材质和绝对时间姿态。

- 修正法线：`../airborne-comparison/assets/normal-object.jpg`。
