# 坑缘高脊：比例平衡与完整窗口预览

预览：http://127.0.0.1:8973/moon-terrain-trial/crew-rim-balance/index.html

从项目根目录启动：`node source-models/moon-terrain-trial/crew-rim-balance/server.cjs`。

## 本版决定

按用户最新修正，优先保证三人坐在坑缘上方、背影可辨、背景自然，允许适度放大，不再坚持严格的正常人物米制比例。人物采用正常比例试排的约2.5倍；在用于设计比较的25米/单位标尺下，坐高约2.9米，属于用户允许适度失真的折中。它不是实测月球地点，也不是完整的物理尺度模拟。

三人放在原地形坑缘的外侧高脊。没有新增平台或抬高地形：`prepare-layout.mjs` 从原有GLB采样高脊顶端较平整的一段，再逐人射线落座。中心约(61.25,7.571,-3.85)，三人x分别61.18/61.25/61.32，沿同一段脊顶并排收近。脚下坡面向下退开，身后为远处月面和星空，避免整面坑壁在人物背后升起、造成坐在坑里的观感。机位从坑缘外侧靠近，保留完整大坑的远景后才转向三人。

三份静态三维GLB直接沿用8971版，未改变已确认的绫波丽、真嗣外形，也保留明日香的棕橙长发、红色驾驶服及深色配件。人物没有图片面片或骨骼动作。人物比例固定，不随镜头放大或移动。

## 原曲时间与镜头

| 时间 | 画面 |
| --- | --- |
| 193–216秒 | 第二圈原远景锚点接近月球，下降展开完整环形山；人物尚不可辨 |
| 216–233秒 | 沿坑缘外侧逐渐靠近高脊，完整大坑退出近处取景范围 |
| 约234秒起 | 三人完整可见，约237秒背影更清楚，先看他们望向画外 |
| 约239–241秒 | 顺着视线缓慢转向，地球从右侧逐渐入画；最早几何擦边为238.9秒 |
| 245秒至曲终 | 三人、坑缘与远地球同框，保留星空；继续缓慢前行和侧移，没有固定机位停留段 |

相机由音频绝对时间驱动，支持暂停、重播与重复定位。255秒到271.726667秒仍移动约0.237场景单位；后半段最低采样速度约0.013单位/秒。当前标尺仅作设计比较，不能将这些参数当成真实登月轨道或精确离地测量。

## 窗口适配

页面固定在当前视口内，窄窗口采用“完整竖幅画面 + 下方紧凑控件”，宽窗口将控件放在右侧。`ResizeObserver` 按画面区实际宽高等比缩放540×960画面，既不拉伸，也不裁切。播放、暂停、重播和时间滑条始终在主要控件区；说明与导出折叠收纳。展开说明时画面仍自动缩小以完整显示。

实际当前浏览器视口为476×991；展开说明时的检查数据仍同时满足 `fullFrameVisible=true`、`controlsVisible=true`，画幅比例误差小于0.00001。收起说明后的窗口截图为 `output/window-preview.jpg`。这是实际浏览器窗口检查，不是微信真机验收。

## 源码、素材与光照

- `camera-path.js`：持续运镜，逐轴单调三次插值避免靠近后反向回弹。
- `shot-config.json`：节奏、关键帧、座位及比例。
- `prepare-layout.mjs`、`terrain-sampler.mjs`：只读采样原地形并生成脊线坐席。
- `characters.js`、`assets/*-seated.glb`：人物源码与实际加载模型；GLB逐字节沿用8971版。
- `scene.js`：地形原有接缝与法线、落座、光影和遮挡检查。右上方太阳继续同时用于地球、人物和地形；局部精细阴影图只补足小人物接触投影，不额外增加照明。
- `earth-calibration.json`、`calibrate-earth.cjs`、`end-pose.json`：对照项目已有微信开发者工具255秒地球参考姿态校准，误差约0.000004度。255秒文件是校准参考机位，之后仍持续运动。
- `viewer.js`、`index.html`：音频播放、时间滑条、当前窗口等比适配、关键帧导出。

复用 `../preview/assets/` 的成熟地形GLB和PBR贴图、`../airborne-comparison/assets/normal-object.jpg` 的法线、`../../mech-encounter-candidates/preview/vendor/` 的Three/GLTFLoader和几何工具。原曲PCM尾段复用 `../descent-to-earth-193/assets/moon-tail-193.wav`，193–271.726667秒，共78.726667秒。星空沿用原小程序模块副本，16000颗星。没有重新造月面。近处仍能看出该轻量素材的细节限制，本版通过小幅放大人物、较远机位和减少近地面取景来平衡。
