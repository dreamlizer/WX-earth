# 悬空环形山三档构图对比

2026-10-20。按用户要求取消贴地近景，只做独立的构图验证。旧版 8962 / 8963 / 8964 和小程序代码保持原样。

启动：`node source-models/moon-terrain-trial/airborne-comparison/server.cjs`
预览：http://127.0.0.1:8965/
结果：`comparison.png`（1656 × 1120），三个 540 × 960 的 WebGL 实渲染画面。

复用已下载的 Oleksiy Rysyuk Free 8K Moon terrain 的 80,000 三角面网格及 2K 材质；使用转换后的物体空间法线。保留相同地形、太阳位置、地球位置，仅比较镜头高度及俯角。未使用 EXR 位移；不是资产离线渲染质量上限。

A：相机 (55,40,140)，看向 (25,8,-70)，低空掠过。
B：相机 (55,60,140)，看向 (25,8,-60)，环形山中景。
C：相机 (55,90,140)，看向 (25,0,-100)，高空俯瞰。

这些是场景坐标与相对高度感，资产没有真实地理尺寸标定，不能当作精确米数。

浏览器已检查三档实际画面：完整主环形山入画，地球未被裁切，画面下缘未露出地形边界；控制台无错误或警告，保存按钮成功生成 PNG。B 适合作为主体构图，C 可作升高后的停留构图。这里只验证静态构图，没有验证运动连续性、手机性能或微信真机表现。
