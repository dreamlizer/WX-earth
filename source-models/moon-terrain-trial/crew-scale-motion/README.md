# 三人比例与持续运镜修订

预览：http://127.0.0.1:8971/moon-terrain-trial/crew-scale-motion/index.html

启动：在项目根目录运行 `node source-models/moon-terrain-trial/crew-scale-motion/server.cjs`。本版与8970版独立，旧版文件指纹保存在 `preserved-crew-v1.json`。不修改小程序、其他歌曲或旧样段，不上传发布。

## 本轮调整

1. 相机在看清人物后持续前进与轻微侧移，撤销229–238秒及255秒以后的固定机位。位置采用逐轴单调三次插值，避免从快速接近转慢速时冲过头、反向退回。255秒到曲终继续移动约2.98场景单位；226秒以后60Hz采样最低速度约0.174单位/秒，直到歌曲结束前仍有运动。
2. 三人的世界比例改为原版约18%（0.60/0.62/0.60，相比3.4/3.5/3.4）。不随时间放大人物；通过相机真实接近看清。216秒人物包围盒约10像素高，224秒约37像素，226秒约58像素，255秒约72像素；背影视觉高度小于完整包围盒，后者包含坐姿伸出的腿和手。
3. 三人坐席中心间隔由9改为1.1场景单位；相对于人物自身大小也收近约31%。绫波丽、真嗣模型文件逐字节沿用，未修改外形/材质；只改世界位置及比例。当前中心位置为x=32.9/34/35.1，z=-19/-19.15/-19，高度从原地形射线求交。
4. 明日香保留红色驾驶服，但长发改为棕橙色分层，肩部、上臂、前臂及腰侧采用深色配件，保留绿色肩部细节。头发、服装与配件不再连成一片红色。

## 镜头节奏

| 原曲时间 | 内容 |
| --- | --- |
| 193–216秒 | 原第二圈远景接近，下降展开完整大环形山；人物是远侧坑缘的小尺度参照 |
| 216–223秒 | 继续从坑内上空接近三人，完整大坑逐渐退出取景边界 |
| 约223–228秒 | 三人完整可辨，先看他们望向远方；地球仍在画外 |
| 约229–231秒 | 镜头抬起，地球从上方逐渐入画，始终保留三人 |
| 234秒至曲终 | 远地球、星空与三人同框，相机继续减速前行和侧移；只在音乐自然结束时停止播放 |

地球的几何边缘第一次进入视锥为228.4833秒；约230–231秒能清楚辨认地球。人物可辨阈值是完整包围盒不小于28像素、三人完整入画且头部没有地形遮挡，检查采样间隔0.5秒。本版不再宣称近处仍保持完整B画幅：先交代B方向的大坑，再通过真实靠近解决人物比例，这是本轮用户要求带来的取景变化。

地形没有真实米制标定，不能把高度说成精确的米。镜头正下方最低离地约16.50场景单位，保持悬空；没有贴着坑壁或地面行进。主体大坑、原地形、贴图和法线均未重新制作。

## 依赖与可编辑源码

- `characters.js`：三人形体、明日香颜色及坐席。仍为自行构造的静态3D背影模型；没有骨骼、图片人形面片。
- `assets/*-seated.glb`：实际加载的三份GLB；总计102240三角形、22个材质批次、2676760字节。
- `export-models.mjs`：运行 `node source-models/moon-terrain-trial/crew-scale-motion/export-models.mjs` 可重建GLB。
- `camera-path.js`：绝对时间驱动的连续镜头，42–44度的后半段视场。
- `scene.js`：地形接缝、阴影、三人加载及射线落座、相机和入画检查。
- `earth-calibration.json`、`end-pose.json`：255秒参考机位与小程序地球朝向换算。虽然文件沿用end-pose名称，本版255秒后仍持续运动。
- `calibrate-earth.cjs`：对照已有微信开发者工具255秒地球姿态记录校准；右上方太阳方向继续统一用于地球、地形、人物。姿态误差约0.000003度。相机变化仅使末帧光线投影有极小变化，仍来自右上。
- 月面GLB与PBR贴图复用 `../preview/assets/`，法线复用 `../airborne-comparison/assets/normal-object.jpg`；Three/GLTFLoader/BufferGeometryUtils复用 `../../mech-encounter-candidates/preview/vendor/`；星空沿用小程序模块副本，16000颗星。原曲PCM尾段复用 `../descent-to-earth-193/assets/moon-tail-193.wav`，画面由音频时间驱动，193–271.726667秒，共78.726667秒。
