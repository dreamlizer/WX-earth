# 三人同望 · 最后帧接地、姿态与光影精修

预览：http://127.0.0.1:8976/moon-terrain-trial/crew-grounded-frame/index.html

本轮只精修271.7266666667秒的最后一帧。精修前为已确认高清月面+原三人，精修后为同一场景中的新坐姿/支撑/材质。两版即时切换，所有旧目录、素材、动态预览及对比图保留。

## 保持与变更

- 保持最终相机位置、四元数、FOV44°、三人根节点位置/排列/整体缩放、地球姿态与大小、星空、原地形和高清材质。太阳方向/强度/曝光不变，未新增照明光源。
- 沿用原三人模型的程序化建模源，保留发型、驾驶服分色和三维网格。修改后的角色仍为真实3D网格；未以图片或人物贴片替换。
- 分别校正两只撑地手、六只鞋底和三个座位。撑手先在附近坡面寻找够得着的位置，再按固定上臂/前臂长度计算肘部，避免直接把胳膊拉长到下坡。脚的位置略收近，用固定腿段长度计算屈膝姿态。根节点、人物间距及整体比例不变。
- 臀部下侧做轻微坐压，并逐顶点约束到实际坡面以上；手掌、鞋底顺着局部坡面放置。肩线、躯干与抬头角度有克制差异，保持安静望向地球的姿态。
- 收敛白色衣料亮度与长发的条束色差，区分衣料/头发/橡胶的粗糙度；接地部位带少量月尘色。没有统一发光描边。
- 缩紧原有零辐射接触阴影相机的覆盖范围（原±0.7，精修±0.28），仍为2048²阴影；该相机只生成阴影，不提供第二个太阳。臀、手、鞋周围另有局部环境遮蔽，作用在间接漫反射上。
- 原地形上添加9粒低矮贴地碎屑，给人物下缘增加少量真实遮挡；不重做大地形，不提亮大面积黑色前景。

## 验证范围

实看完整构图、1080成图及人物局部，并切换精修前后检查姿态、遮挡和受光。相机和三人根节点位置/整体缩放一致。540规格的精修前月面/人物像素与已确认高清静帧一致；两模式的地球、天空与远地形像素一致，变化限制在三人及接触区域。

11个名义支撑点的离地间隙均为0.00008场景单位；另采样实际臀部、鞋底、撑手及手指网格，未发现采样点穿入地形。它是局部支撑检查，不是全身体积碰撞求解；场景单位不是经测量的米。两臂、两腿的关节长度检查通过。页面和WebGL错误均为0，当前窗口完整画面与控件可见。

项目全部41个 `tools/*.test.cjs` 通过，日志见 `output/project-tests.txt`。旧文件SHA-256保留检查见 `checks.json`。

本轮只验证独立浏览器静帧；新坐姿尚未放回动态版本，未进行微信开发者工具/真机/手机性能验收，未上传云端或发布。未新增纹理图；继续跨目录复用已确认高清材质、原三人GLB作为对照、地球/月球/云贴图与vendor。
