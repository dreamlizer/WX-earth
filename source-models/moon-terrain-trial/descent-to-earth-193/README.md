## 空间连接与B基准

`prepare-anchor.cjs`只读当前正式`moon-orbit-sequence.js`及现有Three适配层，在原构图检查场景中依次求值113秒、193秒；将193秒姿态、固定地球和太阳方向通过同一刚性旋转与统一比例转换到独立地形坐标，写入`orbit-anchor.json`。本轮初帧相机位置误差小于1e-8，朝向误差为0。运行该脚本会更新本目录锚点，不写正式代码。

镜头开始之后走新轨迹，不继续照搬原来的第二周。球面远景复用已有月球贴图，局部地形复用原8万面GLB与修正法线，运行时在内存中将其贴合球面并修整外缘。源GLB和贴图没有重导出或覆盖；没有重新生成陨石坑。球面底层持续存在，边缘细节按观察距离衔接，没有整幅画面淡入淡出或靠黑场隐藏切换。地球和太阳全程保持固定世界位置/方向，地球没有瞬移或显隐动画。

B保留已确认的主坑、远地球、留白关系。球面、固定远地球和原轨道空间接入后，构图、地球尺度及太阳方向需要服从统一空间，所以本轮不宣称与原平面B静帧逐像素相同。旧静态B与20秒样段均完整保留。

坐标单位未标定为米。这是视觉尺度候选，不是月球实地测绘落点；全球月球贴图与商用地形块没有真实地理对应关系。这里完成的是同一三维空间里的固定地形区域接近，正式接入仍需评估曲率、分辨率、光照和目标平台。

位置轨迹用带时间节点的三次Hermite曲线，姿态用四元数球面Bezier连续连接；停留节点速度归零。相机没有贴地段。阴影在固定场景上生成一次后复用，避免相机运镜引起阴影重拟合。桌面4096²阴影不作为手机配置。

## 原音乐与时钟

`assets/Zen-moon.mp3`是原音轨的本地副本，5,241,096字节；SHA1为`b6907476df6166a35745ebfeebab0d20f550fe4f`，与此前正式播放核对记录一致。

首轮发现原MP3在浏览器中的VBR时长估算会变化。最终预览使用从**同一原音轨**精确解码的`assets/moon-tail-193.wav`，48kHz、双声道、16bit PCM，3,778,880个采样帧，78.726667秒。未变速、未改曲目、未改变音高，也没有有损二次编码。播放器显示的原曲时间为`193 + audio.currentTime`，结尾以音频原生`ended`事件为准。音量默认80%，可静音。

复现片段：

```bash
ffmpeg -i assets/Zen-moon.mp3 -ss 193 -c:a pcm_s16le -ar 48000 -ac 2 assets/moon-tail-193.wav
```

命令在本目录执行；输出仅覆盖本目录的解码片段。`output/audio-exact.json`记录实际样本数，`output/audio-decode.log`记录解码过程。WAV约14.42MiB用于本地桌面预览，不是手机交付体积方案。
